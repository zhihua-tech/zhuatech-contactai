# ContactAI：联络中心智能质检社区版


## 本次升级：会话处理占用与后处理负载

将通话/会话分钟与后处理分钟合并，扣除休息后核对可用坐席容量和占用率；不把排队等待计为人工服务时间。

新增已认证的结构化录入工作台（`/operations.html`），支持批量核算、逐条结果依据、分级复核和CSV/完整JSON导出。结果由真实后端算法计算，不是预置演示数字。所有数值精确传递，不调用外部模型。

这是**只读核算**：不写库、不审批、不自动执行财务、签署、销毁或设备控制。输入条件满足不是执行授权。[算法、输入边界与接口说明](docs/OPERATIONS-REVIEW.md)。
## 本次功能更新：会话时间线与响应间隔

按坐席与客户发言时间计算有效覆盖、静默、重叠和响应间隔，可定位服务等待问题；输入为已授权转写元数据，不分析员工情绪或绩效。 登录后从「业务计算工具」进入，支持真实后端校验与结果导出。详见[接口、示例与边界说明](docs/AI_BUSINESS_UPGRADE_20261023.md)。本次不改变既有许可及联系方式。

## 不是“自动给坐席打分”

ContactAI 更重视证据与协同：系统先筛查高风险会话，质检人员核对录音和转写，主管处理合规、高额退款及投诉，最后把改进建议交回坐席。社区版不调用外部大模型，便于离线演示和规则测试。

核心分析接口：`POST /api/ai/contact/analyze`。

![H5：质检专员会话工作台](docs/images/contactai-h5.png)

## 功能组成

- 会话接入、AI 初检、风险标签、人工复核、回访闭环
- 负向情绪、等待超时、重复联系、合规话术和高额退款规则
- 录音通道、转写服务、在线客服和坐席健康状态

- JWT 权限、MySQL/Flyway、H2 测试和 Docker Compose

## 输入对照与版本化快照

在既有「会话处理占用与后处理负载」基础上，新增 `/comparison.html`：基准与候选两组数据都由当前真实算法重算，按编号展示新增、移除、逐字段变化和精确数值差，支持筛选、分页和全量导出。原核算入口可导出输入快照，对照页经后端完整校验后整体导入；失败不覆盖当前输入。

快照区分项目、字段契约及算法版本。建议较宽松不代表风险已下降，输入摘要不是签名；操作人和时间仅为响应元数据，不是持久化审计。本次未新增模型调用或业务写入，也不代表全系统生产认证。详见[输入对照操作与接口说明](docs/INPUT-COMPARISON.md)。
